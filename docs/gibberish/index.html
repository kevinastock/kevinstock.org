GibberiSH

February 2026

I thought it would be funny to set up an account with an agent as the shell. There are lots of tools for having llms to help on the command line, but none that I could find are recklessly yolo, and they assume you still want to use the terminal; I really wanted the agent to use the terminal for me and just report the results back.

So I set up a PTY-backed virtual terminal using avt in my process, set up an agent with only one tool, and wrapped that in a REPL. The given tool takes two inputs: a string of bytes (with some escape sequences available) to send to bash, and a float: seconds to wait. The tool sends the bytes, waits, and then returns the contents of the virtual terminal. The agent only ever sees the terminal screen, thus having to use the computer just like the rest of us.

This is fun because the agent isn’t just executing processes, it’s driving the whole terminal. It can wait for long running programs, it can do bash job management. It can play NetHack!

Clearly the models are trained to execute commands that will terminate; they required some encouragement to edit files with vim etc. But it was able to install and play nethack without any trouble.
